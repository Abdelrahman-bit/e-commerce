# 🛒 E-Commerce Platform – User Guide

This document explains how to use the platform for **Customers**, **Sellers**, and **Admins**.  
It covers browsing products, managing accounts, and completing transactions.

---

## 👤 Customers

### 1. Browse Products
- Visit the **Home** or **Products** page.
- Use filters or the search bar to find products by category or keyword.
- Click a product card → opens the **Product Details Page** (image, description, price, seller info).

**Example:**
```bash
Go to: /Products.html
Click on "Laptop"
→ You’ll see full details + “Add to Cart” button
